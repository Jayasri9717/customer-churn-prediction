Project workflow

The repository's Python pipeline is organized into four tasks.

01
Load & explore

Inspect rows, data types, missing values, duplicates, and churn distribution.

02
Clean the dataset

Normalize labels, handle missing charges, remove duplicates, and check invalid values.

03
Train the classifier

Encode categorical features and train a logistic regression model with a holdout split.

04
Review predictions

Evaluate output and use risk signals to help prioritize customer retention.
